# Script template

Output the script in exactly this structure.

````markdown
# <Brand> <Topic> Video Script
<Draft | Final review copy> • <D Month YYYY> • <runtime target, e.g. ~2:00>

Three-column production script. Each row is a frame. Blank cells indicate no element;
a blank Visual cell indicates a dark background.

| Voice-over | On-screen text | Visual |
|---|---|---|
| <spoken line> | <HEADLINE / KEY FIGURE> | <what the viewer sees, as a direction> |
| ... | | |

## Production Notes
- Assumptions and illustrative figures (state each; say what the number is NOT)
- Calculation shown step by step: `A × B × C = result`
- Footage guidance: what must be real capture vs. stock vs. animation
- Claim guardrails: anything that must match confirmed facts before release

## Sources
- <Figure>: <Publisher>, <date>, "<title>". <URL>
````

## Column rules

**Voice-over** — exactly what is spoken, in order, one idea per row. Spell out numbers
the way they are said ("seventy-percent", "nearly twelve million dollars"). Leave blank
for silent beats (stings, title cards, end sound).

**On-screen text** — UPPERCASE headline or key figure, max ~8 words, reinforces rather
than repeats the voice-over. Use `·` to separate lockup parts and `→` for flows. Put a
smaller secondary line (calculation, "Illustrative target model") on its own line under
the headline. Leave blank when the visual should carry the beat.

**Visual** — one sentence, present tense, directed at the editor / animator: what
appears, what moves, what transitions into what. Specify footage type when it matters
("actual engineering footage", "illustrative animation"). Name pacing notes (pause,
acceleration, hold) and the final sound/sting.

## Row sizing

- 1 row ≈ 1 beat ≈ 3-6 s; voice-over per row 8-25 words.
- Number rows implicitly by order; do not add a number column.
- Group acts with a blank-voice-over transition row only when the visual changes world.
- Long scripts may split the table across pages/sections but keep the header row repeated.
